# Versionsmatrix K1 Support-Agent

Je Workflow-Version steht hier, was es dazu im Repository gibt: Plan, Testtabelle, Tages-Doku und Workflow-Export. Jede Zelle ist entweder ein Link auf eine Datei im Repository oder ein Satz „gab es nicht: <Grund>“. Eine Lücke steht also sichtbar da und wird nicht verschwiegen. Die Datei wird bei jeder neuen Version nachgezogen und vom Prüfer `check-abgabe-repo.ps1` gegen die Dateien im Repository gelesen.
